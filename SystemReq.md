The document is a system requirements architecture for PricerAI project
the goal is to create github page based web application that will prodide web auditory with comparison for AI services
the backend will run on 10.0.0.20 (raspberry PI) and daily collect prices from AI providers and commit push them to github repository
features:
1. Price per 1b tokens per providers(include all permutations like input/output, models etc)
2. price history
3. special AI services prices
4. price per basic task(for example generate image, create book etc)
